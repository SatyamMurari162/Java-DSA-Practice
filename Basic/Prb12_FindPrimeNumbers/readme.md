P12. Find All Prime Numbers up to N (Sieve of Eratosthenes)

Problem: List all prime numbers up to 50.

Approach:
Instead of checking each number individually (slow), use the Sieve of Eratosthenes: start with all numbers marked
'prime', then for each prime found, mark all its multiples as 'not prime' — vastly more efficient for finding MANY primes
at once.
