P1. Check Armstrong Number

Problem: An Armstrong number is one where the sum of its own digits, each raised to the power of the number of
digits, equals the number itself (e.g., 153 = 1³+5³+3³). Check whether 371 is an Armstrong number.

Approach:
Convert the number to a string to get its digit count, then sum each digit raised to that power. Compare the sum to the
original number.
