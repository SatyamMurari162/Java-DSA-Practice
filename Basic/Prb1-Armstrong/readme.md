
Problem:--  An Armstrong number is one where the sum of its own digits, each raised to the power of the number of
digits, equals the number itself (e.g., 153 = 1³+5³+3³). Check whether 371 is an Armstrong number.


Appraoch :-- First I will count the number of digits in the given number. Then I will extract each digit one by one, raise each digit to the power of the total number of digits, and add all those values. Finally, I will compare the calculated sum with the original number. If both are equal, the number is an Armstrong number.

Example: - 371 (3^3+7^3+1^3) == 371 give true so, this number is armstrongnumber.
